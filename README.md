# SUMExXx.github.io

Suman Debnath — profile and blog. Next.js, statically exported to GitHub Pages.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # builds and copies the site into the repo root (index.html, index.css, ...)
npm start          # serve the root locally
```

Commit the rebuilt root and push to `main`; GitHub Pages serves it. See [AGENTS.md](./AGENTS.md).
